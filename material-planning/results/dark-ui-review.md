后续更新（2026-10-26）：已执行完整前端回归和新增检查，共105项断言通过，补齐下文当时未完成的390px、异常请求及导出内容验证。详细结果见 [回归报告](ui-regression-2026-10-26/README.md)。本文件以下保留2026-10-25的实际检查记录。

## 设计与范围

- 深蓝背景 #0B1220，蓝灰面板 #131E30，青色主操作 #45D6CF，浅色文字与琥珀色风险数字。
- 延用原生 HTML/CSS/JavaScript 和过程式函数，未引入前端框架或外部在线依赖。
- 桌面侧栏；900px 以下顶部导航；600px 以下单列配置与双列数据概览。
- 概览展示真实记录数量，增加任务选中计数。四张表、CSV、数据保存、计算、历史及导出沿用原有接口。
- 分区仅切换可见性，保留输入；校验错误可跳回基础数据并聚焦字段；历史结果自动进入计划页。
- 示例加载失败在基础数据页显示；历史读取失败在历史页显示。

## 本次实际验证

通过 Codex 浏览器在独立临时 SQLite 数据库、端口 8771 上操作，正式 8765 页面仅做展示及导航检查。

| 场景 | 观察结果 |
|---|---|
| 默认示例与数据概览 | 物料4、BOM3、库存4、任务2，与表格相符 |
| 三分区导航 | 页面标题、导航高亮、可见工作区同步切换 |
| 正常计算 | HIGH → LOW；生产4行、采购4行、风险0；成功保存历史 |
| 小数需求1.5 | 校验未通过，展示需求数量问题 |
| 错误定位 | 返回基础数据；焦点为“生产任务第1行 需求数量” |
| 保存数据 | 显示“已保存”时间；历史计划仍保留 |
| 跨区保留编辑 | 修改任务数量为60后查看历史，再返回仍为60、仍提示未保存 |
| 新增与删除 | 新增BOM第4行时概览更新为4，删除后回到3 |
| 历史查看 | 自动进入计划计算，标记“历史计划 · 只读”，输入快照入口可见 |
| 历史导出 | 点击下载CSV后显示“已导出计划”；未重新校验所有五种CSV文件内容 |
| CSV无文件校验 | 提示至少选择一个CSV文件，应用按钮禁用 |
| 桌面1280px | 侧栏及结果双列布局正常，页面内容宽1265px，无整体横向溢出 |
| 窄屏867px | 顶部导航、并排配置与任务选择正常，内容宽852px，无整体横向溢出 |
| 浏览器控制台 | 已操作的测试页面未记录error级别日志 |

静态检查：app.js、verify_workbench.cjs、verify_persistence_ui.cjs、verify_csv_ui.cjs 均通过 Node 语法检查；HTML 标签配对和 ID 唯一性另行检查。
