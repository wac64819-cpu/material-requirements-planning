# E3 详细设计

2026-10-15已在原简版基础上补齐技术扩展稿；原简版保留。当前首选阅读文件是 [英文 Word 报告](E3-detailed-design-en.docx)，另有[可编辑 Markdown](E3-detailed-design-en.md)。

扩展稿包含14个关键过程的输入输出、前置条件、伪代码、后置条件与异常说明，覆盖全部6个子系统；提供2张流程图、2张N-S图、2张业务决策表，以及现有代码函数/行号映射、E4/E5衔接和待填写的小组记录。

用户已确认小组为2人。E3原文写“子系统至少为人数两倍”，现有6个子系统满足至少4个；14个细化模块也满足按模块解释时的数量要求。数量满足不等于课程最终验收完成，真实姓名、分工、全员评审及个人贡献尚需填写。

关键文件：

- `build_expanded.py`：生成扩展稿、四张PNG算法图与代码映射清单。
- `design-manifest.json`：14个模块对应函数、行号、源码与原始实验要求哈希。
- `verify_expanded.py`、`verification-expanded.json`：结构/映射和独立算例核对。
- `qa-expanded/`：内部排版检查用PDF、逐页PNG及页面文本，不作为额外提交文件。
- `verification-expanded.md`：内容核对及实际渲染方式说明。

当前实现中的需求合并和净生产展开在M30内，余量抵扣在M40内，不冒充独立Python函数。CSV整表替换、三张物理表、静态规则版本和只读历史等E2到实现的差异已在报告中注明。
