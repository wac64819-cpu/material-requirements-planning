# 工作台界面升级

目标：让课程项目的真实需求计算、共享库存分配和采购规则更易理解与演示。

视觉：精致工业管理台；暖白 #F5F3EE、石墨 #252B31、灰蓝 #536879、鼠尾草绿 #637765、陶土 #A2634B。
字体：Segoe UI / Microsoft YaHei，数字使用 Consolas。沿用原生 CSS 与 JavaScript，避免增加构建依赖；图标采用 Lucide 风格线性 SVG。
布局：固定窄侧栏、宽内容区；首页采用 2:1 主次布局，数据列表与右侧编辑抽屉分离。移动端横向导航，表格容器内滚动。

## 范围与验收

- 总览：当前数据任务、选中任务、计算后的缺料种类与风险、最近计划；未计算或输入变化后不能伪装为零风险。
- 数据：可读表格、关键词搜索、分类筛选、分页、固定表头、状态标签；抽屉编辑提供应用与取消；保留快速表格编辑。
- BOM：从当前基础数据展开的树，可选择根物料、折叠节点、查看单件用量与库存；检测循环并限制超大展开。缺口仅来自有效计算，不用理论用量冒充净需求。
- 结果：保留原生产采购表和 CSV，增加毛需求→库存抵扣→净需求说明，点击数量查看真实来源路径和采购取整依据。
- 时间轴：按当前结果或历史快照显示采购、生产和交付日期；早于基准日的事件突出显示，所有日期保持原算法语义。
- 历史：保持只读快照和原编辑数据隔离，提供列表搜索；数据库仍在本机。
- 可访问性：键盘导航、抽屉 Escape 取消与焦点恢复、语义标签、390px 页面不横向溢出、减少动态效果偏好。
