## 发现与处理

- DEF01：合法大小的 CSV 长字段触发默认解析上限，误报语法错误。已将字段解析上限与 500000 字节文件约束对齐，边界与回归测试通过。
- OBS01：纠正初版测试对原生 JSON 整数上限的假设，CSV 和浏览器的安全整数约束单独验证。
- OBS02：Windows 超大请求曾偶发连接中断。最终运行取得预期 413 状态；完整错误正文稳定交付尚未证明，不标记为已修复。
